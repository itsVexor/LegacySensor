🚀 Latest release · BETA

Legacy Sensor v1.7.0 Beta

The November 2026 update brings a redesigned desktop experience, offline customization and rewards, refreshed Phone Sensor / WebApp and new ways to play. This is the Windows beta — thank you for testing! 💗

Released 15 November 2026 · Windows BETA

✨ New in v1.7.0 Beta

  • Player Card + Locker Room: brand-new profile card, avatar, border, background, style, alias, badge and effect customization.
  • Levels & rewards: XP progress, Challenges, Legacy Coins, Gift Machine, Collection Book and session results.
  • Quiz Time: new mouse-controlled offline mini-game with difficulty levels, visuals and sounds.
  • Party Master: local parties and up to five dance bots with Easy / Medium / Hard difficulty options.
  • Photo Booth: capture photos with stickers and your selected look.
  • Phone Sensor / WebApp: refreshed iOS/Android interface, local profile look, QR pairing and avatar/gallery improvements.
  • New presentation: refreshed startup intro, card previews, polished effects, updated visuals and seasonal options.

🛠️ Fixed & improved

  • Resolved missing avatars, borders and backgrounds in packaged Windows EXE builds.
  • Fixed local WebApp HTTPS / WebSocket startup and Party Master integration errors.
  • Improved bundled dependencies, QR pairing resources and WebApp file loading.
  • Improved the Player Card / Customize preview and its asset handling, while preserving the existing tracking and scoring functions.

🔄 Changed or removed

  • Account Login / Register is not required for the current offline-first beta; the website login interface was removed.
  • Previous unstable online-bot experiments have been replaced by local AI dance bots. The local Phone Sensor party pairing is separate from internet matchmaking.
  • Just Dance Liminal was removed from the website's compatibility table pending verification; no game integration is promised for that title.

🎮 Compatibility note: Legacy Just Dance PC by DIEGUINHODG remains the recommended game. Coach selection in Dreyn JD2021 PC is still under investigation.

🧪 Beta notice: Features and performance may vary depending on your PC, camera and supported game. This release is not an official Ubisoft product.

FAQ

Quick answers

Do I need a Kinect?

No. Legacy Sensor is designed to use a webcam or supported virtual camera source for tracking.

Can I use my phone as a webcam?

Yes, if your phone-camera software exposes a virtual webcam source that Windows and Legacy Sensor can access.

Is Legacy Sensor free?

Yes. Legacy Sensor is currently released as a free beta.

How do I run the Linux version?

Download and extract the Linux v1.6.0 Beta ZIP. Open a terminal in the extracted folder, run chmod +x LegacySensor-v1.6.0-BETA, then start it with ./LegacySensor-v1.6.0-BETA. The Linux build is intended for Linux Mint / Ubuntu-based systems. Please note that the Linux 1.6.0 build is on an older release branch than Windows 1.7.0 Beta.

Which games are supported?

Legacy Just Dance PC by DIEGUINHODG is the recommended, fully working setup. Recent Legacy Sensor releases do not currently provide reliable support for JD2021 PC by Dreyn. See the compatibility table for the current status.

Does it work with any webcam?

Most standard Windows webcams should work, and supported virtual camera sources can work too. Camera drivers and virtual-camera software may affect compatibility.

Can two people play at the same time?

Experimental two-player tracking is documented in earlier releases, including v1.3.0. Availability and performance depend on the Legacy Sensor version, camera and game build; check the version notes before relying on it.

Why can Windows or antivirus show a warning?

Independent packaged apps can trigger SmartScreen reputation or heuristic warnings. Download only from the official project page and do not disable antivirus protection. SHA-256 checksums will be published when they are available for the exact release archives.

Where can I find help if something does not work?

Open the Troubleshooting guide for camera, tracking, pairing, firewall and game compatibility checks.

Does the website need a backend?

No. The public project page is static, so it can stay online without your PC running and serve release links and setup guides.

Is this an official Ubisoft application?

No. Legacy Sensor is an independent fan-made project by ItsVexor and is not affiliated with or endorsed by Ubisoft.
