Before you start

Quick setup checklist

01

Install cleanly

Download the ZIP from the official project page and extract the entire archive to a normal folder. Do not run the app from inside the ZIP.

02

Prepare the camera

Choose the correct webcam or supported virtual camera in Legacy Sensor. Keep your full body visible and avoid strong light behind you.

03

Check the game

Use a game and version listed as supported. Legacy Just Dance PC by DIEGUINHODG is currently the recommended setup.

Camera & tracking

Common problems

My camera is not detected
  1. Close apps that may already be using the camera, such as video-call software, OBS or another camera utility.
  2. In Windows, open Settings → Privacy & security → Camera and allow camera access for desktop apps.
  3. Reconnect the USB camera, try another direct USB port and reopen Legacy Sensor.
  4. In the app, select the correct camera source. Virtual cameras may have their own start/enable switch.
The body or joints are not tracking correctly
  1. Move farther back until your whole body, including feet and hands, fits inside the camera frame.
  2. Face the camera and keep the room evenly lit. Avoid bright windows or lamps directly behind you.
  3. Make sure the camera is stable and not being moved during play.
  4. Try the camera test / tracking view before opening the game.
Tracking is delayed or FPS is low
  1. Close other camera, browser and video applications that are using CPU or GPU resources.
  2. Try a lower camera resolution or FPS setting in Legacy Sensor, then compare smoothness.
  3. Connect a USB webcam directly to the PC instead of through an unpowered hub.
  4. Improve room lighting so the camera does not need to compensate for a very dark scene.

There is no published minimum CPU/GPU specification yet. As a practical starting point, a 720p camera running around 30 FPS is useful where your camera and PC can sustain it; this is a recommendation, not a guaranteed minimum.

Phone Sensor / WebApp

Pairing and network help

Phone cannot connect

  • Connect the phone and PC to the same local Wi-Fi network.
  • Avoid guest Wi-Fi networks or router settings that isolate wireless devices from each other.
  • Temporarily disable VPN on the phone and PC while pairing.
  • Refresh the WebApp and scan the current QR code again.
Open the pairing walkthrough →

Windows Firewall warning

  • Allow Legacy Sensor on Private networks when Windows asks, if you trust the local network.
  • Do not allow it on public networks unless you have a specific reason.
  • Do not forward router ports to the internet for local Phone Sensor pairing.
  • If you previously blocked the app, review its Windows Defender Firewall permission and retry.
Game compatibility

The game does not receive input

Legacy Just Dance PC

This is the currently recommended and fully working game setup. Confirm that you are using the supported PC build and the current Legacy Sensor release, then follow the setup guide included with the app.

JD2021 PC by Dreyn

Recent Legacy Sensor releases do not currently provide reliable support for this game. Historical screenshots or older app versions do not mean that the current release supports it. Older versions, including v1.4.0, need separate testing.

Before changing DLLs or configuration files, make a backup of the game folder. Use only files and steps explicitly provided for the exact game build you are testing.

Linux

Linux launch checklist

The current Linux package is v1.6.0 Beta; the latest Windows beta is v1.7.0. Linux is on an older release branch.

  1. Extract the complete Linux ZIP to a folder you can write to.
  2. Open a terminal in that extracted folder.
  3. Make the application executable with the command shown in the download section: chmod +x LegacySensor-v1.6.0-BETA.
  4. Launch it with ./LegacySensor-v1.6.0-BETA.

That package is intended for Linux Mint / Ubuntu-based systems. Other distributions may need additional dependencies.

Still stuck?

Send a useful bug report

When reporting a problem, include these details so it can be reproduced:

  • Legacy Sensor version (for example, v1.7.0 Beta).
  • Windows or Linux version.
  • Game name and exact game build.
  • Camera model or Phone Sensor device, plus selected resolution / FPS.
  • What you expected, what happened instead, and the steps just before the issue.
  • A screenshot or the relevant application log, if available. Remove personal information before sharing logs publicly.
